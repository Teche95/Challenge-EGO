# Toyota Models App

Aplicación web desarrollada con **React + Vite** que permite visualizar modelos de vehículos, filtrarlos por segmento y acceder al detalle de cada modelo.

---

### 🛠️ Pasos para levantar el proyecto

<!-- #### 1. Clonar el repositorio: -->

#### 1. git clone https://github.com/Teche95/Challenge-EGO.git

<!-- #### 2. Ingresar a la carpeta del proyecto: -->

#### 2. cd challenge-ego

<!-- ### 3. Instalar las dependencias: -->

#### 3. npm install

<!-- ### 4. Iniciar el servidor de desarrollo: -->

#### 4. npm run dev

## 🚀 Tecnologías utilizadas

- React
- Vite
- TypeScript
- React Router DOM
- Tailwind CSS
- Lucide React

## 📦 Version de NODE utilizada

- **Node.js** v22.19.0 

## Verificar versiones:
  node -v
